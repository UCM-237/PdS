# Procesamiento De Señales
Este repositorio contiene código y material de apoyo al estudio de la asignatura Procesamiento de Señales del Grado en Ingeniería Electrónica de Comunicaciones.

## Evaluacion continua
La estructura propuesta para los proyectos de evaluacion está en `Proyecto_de_Evaluacion/`.

Incluye cinco temas:
- Registro de carrera
- Audio con ruido
- Imagen de codigos de barras
- ECG
- Imagen con ruido
