\section*{Objetivos}

El objetivo de esta pr\'{a}ctica es que el alumno se familiarice con los filtros FIR
 habituales para el tratamiento de se\~{n}ales 2D, as\'{i} como con en el dise\~{n}o de filtros
espec\'{i}ficos utilizando la especificaci\'{o}n en el dominio de la frecuencia.

Para alcanzarlo, utilizar\'{a} las funciones que Matlab proporciona para obtener dichos
 filtros, cuyo uso se explica en este gui\'{o}n. Una vez obtenido el n\'{u}cleo de convoluci\'{o}n
de cada filtro ($h(x,y)$), observar\'{a} su espectro, y lo aplicar\'{a} a una imagen con el objeto
de observar el efecto sobre la misma, tanto en el dominio espacial (representando la
imagen original y la imagen transformada directamente) como en el dominio de la frecuencia
 (representando sus espectros correspondientes).

\section*{Instrucciones para realizar la práctica}
\begin{itemize}
	\item La práctica se realizará de forma individual. Los resultados de la práctica, incluyendo las justificaciones y respuestas a cada tarea, se comentarán en un informe (en formato pdf) dividido en el mismo número de secciones que este guión.
	El informe no deberá contener el código, éste se entrega aparte como se especifica en los siguientes puntos. Para cada apartado se mostrará el espectro del filtro utilizado, la imagen original y modificada, as\'{i} como su representaci\'{o}n en el dominio de la frecuencia
	\item Cada tarea se resolverá mediante un programa diferente en Matlab, cuyo fichero .m será entregado en un fichero comprimido junto con el informe.
	\item Cada programa será nombrado de acuerdo con la tarea a la que corresponda (por ejemplo Tarea1.m será el nombre del programa de la primera sección).
   	\item En caso de que un programa no ejecute correctamente, el resultado de la tarea no se considerará válido.
\end{itemize}

\section*{Filtros digitales FIR 2D habituales}

El objetivo de esta secci\'{o}n es generar cada uno de los posibles tipos de filtros que la
funci\'{o}n de Matlab \color{blue}fspecial \color{black} proporciona, observar como los par\'{a}metros influyen en el espectro
del filtro, y utilizarlos sobre una imagen elegida por el alumno, para ver su efecto,
tanto en el dominio espacial como en el de la frecuencia.

\begin{itemize}
\itemP  \textbf{Filtrado de una imagen mediante el filtro promedio (average), circular (disk) o guassiano (gauss) de diferentes tama\~{n}os}


\itemP  \textbf{Filtrado de una imagen mediante el filtro laplaciano (laplacian) o laplaciano gaussiano (log) de diferentes par\'{a}metros}



\itemP  \textbf{Filtrado de una imagen mediante el filtro de movimiento (motion) con diferentes par\'{a}metros}

\itemP  \textbf{Filtrado de una imagen mediante filtros de ensalzado de bordes (prewitt o sobel)}

\end{itemize}
