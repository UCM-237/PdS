# Código de partida (Matlab / Octave)

Ejecuta los scripts desde esta carpeta: `hito1`, `hito2`, … No hace falta ninguna toolbox.

- `actividades`, `cargar_actividad`: lectura de las actividades reales y de las sintéticas.
- `verdad_desarrollo`: tipo, σ e instantes de cambio de las sintéticas de desarrollo.
- `evaluar_detecciones`: TP, FP y FN con tolerancia.
- `ema`: la media móvil exponencial de `entrenamiento/main.py`.
- `guardar_prueba`: fichero de entrega del H4.
- `hito1.m` … `hito4.m`: esqueletos con `TODO`.
