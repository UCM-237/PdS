# Registro de carrera

Proyecto centrado en una señal de actividad fisica tipo Strava, reloj deportivo o registro IMU.

## Idea tecnica
Analizar una serie temporal para detectar cambios de ritmo, paradas, tramos anomales y patrones de esfuerzo.

## Hitos
1. Analisis inicial de la señal.
2. Preprocesado y limpieza.
3. Extraccion de caracteristicas.
4. Clasificacion o deteccion de eventos.
