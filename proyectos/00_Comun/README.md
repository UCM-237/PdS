# Comun

Material compartido por todos los proyectos de evaluacion.

## Contenido previsto
- `Plantilla/`: cabecera o esqueleto base para enunciados y entregas.
- `Rubrica/`: criterios de correccion y pesos por hito.
- `Datos_Ejemplo/`: ejemplos pequenos para pruebas rapidas.
- `Utilidades/`: funciones comunes de carga, visualizacion o metricas.
- `Figuras_Comunes/`: esquemas reutilizables en varios proyectos.
