# Código de partida (Python)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python hito1.py
```

- `utilidades.py`: lectura del audio, SNR, espectro, STFT e inversa, y guardado de figuras en `figuras/`. No hace falta tocarlo.
- `hito1.py` … `hito4.py`: un esqueleto por hito. Se ejecutan tal cual y dejan marcado con `TODO` lo que tienes que completar.
