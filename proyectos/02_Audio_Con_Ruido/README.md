# Audio con ruido

Proyecto centrado en una senal de audio degradada por ruido aditivo o impulsivo.

## Idea tecnica
Comparar espectros, estimar SNR y aplicar filtrado para recuperar la informacion util.

## Hitos
1. Inspeccion temporal y espectral.
2. Identificacion del ruido.
3. Denoising o filtrado.
4. Evaluacion cuantitativa por SNR o criterio perceptual.
