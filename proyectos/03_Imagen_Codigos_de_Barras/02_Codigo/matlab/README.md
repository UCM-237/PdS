# Código de partida (Matlab / Octave)

Ejecuta los scripts desde esta carpeta: `hito1`, `hito2`, … No hace falta la Image Processing Toolbox.

- `cargar`, `codigos_desarrollo`: lectura de imágenes y de los códigos de desarrollo.
- `modulos`, `ean13_tablas`, `digito_control`: tablas y reglas del EAN-13.
- `enderezar`: giro de una imagen con `interp2`.
- `gauss`, `filtrar_sep`, `rellenar`: filtros separables con bordes reflejados.
- `bordes`: cruces de un umbral con precisión subpíxel.
- `guardar_lecturas`: fichero de entrega del H4.
- `hito1.m` … `hito4.m`: esqueletos con `TODO`.
