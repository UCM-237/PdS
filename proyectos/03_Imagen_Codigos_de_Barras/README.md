# Imagen de codigos de barras

Proyecto centrado en una imagen con uno o varios codigos de barras, con posible ruido, inclinacion o iluminacion irregular.

## Idea tecnica
Detectar la region de interes, realzar contrastes y recuperar o validar la informacion codificada.

## Hitos
1. Deteccion de barras o region de interes.
2. Realce y segmentacion.
3. Recuperacion o decodificacion.
4. Validacion de resultados.
