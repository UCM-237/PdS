# Código de partida (Matlab / Octave)

Ejecuta los scripts desde esta carpeta: `hito1`, `hito2`, … Funciona en Matlab (Signal Processing Toolbox) y en Octave (paquete `signal`).

- `cargar`, `anotaciones`: lectura de registros y anotaciones (índices desde 1).
- `evaluar`: VP, FP, FN, Se y VPP con tolerancia.
- `psd_welch`, `picos_locales`: PSD de Welch y búsqueda de picos, iguales en Matlab y en Octave.
- `guardar_latidos`: fichero de entrega del H4 (índices desde 0, como las anotaciones).
- `hito1.m` … `hito4.m`: esqueletos con `TODO`.
