# Imagen con ruido

## Contexto
La imagen presenta ruido impulsivo, gaussiano o mixto, con posible degradacion de detalle fino y bordes.

## Objetivo
Reducir el ruido preservando la estructura visual importante y comparar metodos de restauracion.

## Tareas
1. Identificar el tipo de ruido.
2. Probar un filtrado basico.
3. Probar un metodo mas selectivo o adaptativo.
4. Comparar nitidez, detalle y supresion del ruido.
5. Justificar que metodo es mejor segun el caso.

## Entregables
- Memoria con comparacion de metodos.
- Codigo y figuras intermedias.
- Imagen final restaurada.

## Criterios de evaluacion
- Identificacion correcta del ruido.
- Comparacion razonada de metodos.
- Equilibrio entre supresion de ruido y preservacion de detalles.
