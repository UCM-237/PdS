# Código de partida (Matlab / Octave)

Ejecuta los scripts desde esta carpeta: `hito1`, `hito2`, … No hace falta ninguna toolbox.

- `cargar(n)`, `cargar(n, true)`: imagen con ruido o limpia (solo las de desarrollo).
- `psnr_db`, `ssim_medio`: métricas de calidad.
- `filtrar_sep`, `rellenar`: filtros separables con bordes reflejados.
- `placa_zonal`, `espectro_2d`, `frecuencias_2d`: patrón de prueba de aliasing y espectro 2D centrado.
- `guardar_restaurada`: fichero de entrega del H4.
- `hito1.m` … `hito4.m`: esqueletos con `TODO`.
