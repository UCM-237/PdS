# Código de partida (Python)

```bash
pip install -r requirements.txt
python hito1.py
```

- `utilidades.py`: lectura de imágenes (`cargar(n)`, `cargar(n, limpia=True)` para las de desarrollo), `guardar_restaurada`, `psnr`, `ssim`, `filtrar_sep` (filtros separables con bordes reflejados), `placa_zonal`, `espectro_2d` y `frecuencias_2d`.
- `hito1.py` … `hito4.py`: esqueletos con `TODO`. El del H4 escribe `restaurada_1.png` … `restaurada_6.png`.
