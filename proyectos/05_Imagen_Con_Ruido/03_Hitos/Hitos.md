# Hitos

## Hito 1: tipo de ruido
- Inspeccionar visualmente la imagen.
- Argumentar si el ruido es impulsivo, gaussiano o mixto.

## Hito 2: filtrado basico
- Aplicar un filtro sencillo como mediana o suavizado.
- Comparar con la original.

## Hito 3: restauracion adaptativa
- Probar un metodo mas especifico.
- Afinar parametros para preservar bordes.

## Hito 4: comparacion de metodos
- Comparar resultados con una metrica o criterio visual.
- Elegir el mejor segun el caso.
