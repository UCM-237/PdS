# Imagen con ruido

Proyecto centrado en una imagen degradada por ruido sal y pimienta, gaussiano o mixto.

## Idea tecnica
Comparar tecnicas de restauracion y justificar cual funciona mejor segun el tipo de ruido.

## Hitos
1. Identificacion del tipo de ruido.
2. Filtrado basico.
3. Restauracion adaptativa.
4. Comparacion de metodos.
